# 资产文档模板 · assets_prompts.md

放在项目文件夹里（建议 `03_分镜与提示词/assets_prompts.md`）。整份文档是"生成清单"：导演照着一条一条生成，生成的图按条目名命名。

```
# 《片名》资产提示词文档
版本：v1（日期）
来源：剧本（第N稿）+ 分镜脚本；资产清单：assets_inventory.md
风格带（每条提示词都原样带上）：<千禧年代写实 · 冷灰蓝低饱和 · 单一光源 · 16:9>
状态：待导演逐条生成 → 生成后在条目后标 √ 与文件名
```

## 一、人物资产

**两层结构，每层只写该层该写的**：

- **身份图**（每人物一条）——把这张脸钉死。逐项写足：脸型 / 额头 / 眉 / 眼（形状、眼距、单双眼皮、眼袋）/ 鼻（鼻梁、鼻头、鼻翼）/ 嘴（唇厚、唇形、嘴角）/ 下巴 / 肤色 / 发型发色（长度、分缝、发量、鬓角）/ 体态 / 手 / **独特识别特征**（痣、疤、缺牙、斑、纹过的眉…）。
  标准：细到换一个模型也能生成同一张脸。
- **变体图**（变化时才有）——**只写变化的部分**：换了什么衣服、身体发生了什么（湿透 / 带伤 / 被绑 / 换发型 / 换发色）。
  五官、脸型、发型、体型一律写"**严格照抄上传的身份参考图**"，不重复描述。

操作顺序：先用身份图生成人物图并命名保存 → 之后做别的服装时，上传那张身份图 + 变体提示词，生成同一个人。

```
### <人物名>·身份                     ← 只此一条写足五官
用于：全部相关镜次
【面部】脸型…；额头…；眉毛…；眼睛…；鼻子…；嘴…；下巴…；肤色…
【面部独特特征】痣 / 疤 / 缺牙 / 老年斑 / 红血丝…（必须独一无二）
【发型】长度、分缝、发量、鬓角、发色（含染过又褪色的状态）
【体态】年龄、身高感、骨架、习惯性姿势
【手与细节】手指、指甲、永久疤痕
【背景与光线】干净单色背景；光从…，均匀
【禁止出现】不要换发型/发色，不要夸张线条，不要性感姿势，不要别人，不要文字水印，不要裁切身体

### <人物名>·<变体名>                  ← 只写变化
用于：sc…
【不变的部分】面部五官、脸型、发型发色、体型，**严格照抄上传的身份参考图，完全是同一张脸**
【变化的部分】换成了什么衣服 / 身体状态发生了什么（逐项写死）
【背景与光线】…
【禁止出现】不要换脸或换发型；<这一条变体最容易跑偏的地方逐条写死>
```

## 二、场景资产（每个场景 4 个方向）

先写**布局说明**，再写四条方向提示词。四条必须互相不打架——门在哪面墙，四条里都只能在那面墙。

```
### <场景名>（时间 · 内/外）
用于：sc3, sc4 …
#### 布局说明（写死，四个方向共用）
- 北面墙：<门/窗/家具>
- 东面墙：<…>
- 南面墙：<…>
- 西面墙：<…>
- 地面：<材质>　天花板/光源：<唯一光源位置>
- 家具位置唯一：<沙发×1、茶几×1、电视柜×1、桌×1 …>

#### B1 <场景名>·北向（摄像机站在北墙位置，朝南拍）
提示词：
【画面范围】<这个方向能看到什么：哪面墙、哪件家具、门的哪一侧>
【固定事实】<这一方向必须与另外三向一致的事实，逐条重写>
【禁止出现】<不能多出一扇门／不能出现第二个窗户／不能改变家具位置／不能出现第三个方向才有的东西>。
【光线】四个方向共用同一条光源设定：<…>

#### B2 <场景名>·东向（摄像机站在东侧，朝西拍）  …同结构
#### B3 <场景名>·南向 …   #### B4 <场景名>·西向 …
```

## 三、道具资产

```
### <道具名>
用于：sc1, sc7 …
状态与规则：<当前状态 + 永久规则，例如"钱包是三张红色一百元；不是十元；只有一个">
提示词：
【主体】<材质、颜色、尺寸感、磨损程度的客观描述>，单独一个，正面朝镜头，摆在干净平面上。
【禁止出现】不要出现第二个，不要出现文字商标，不要出现手或人。
```

## 使用纪律

1. 一条提示词只放**一个主体**：人物图不塞两个人，道具图不塞两只手。
2. 所有资产图共用**同一条风格带**，逐字相同。
3. 生成的图**按条目名命名**（如 `A2_陈宇_湿透.png`），存进资产文件夹；条目后标 √。
4. 任何一条生成不理想，先告诉我问题，我改提示词（v2），不要自己在提示词里加词——加了就破坏了"同一条风格带"的一致性。
5. 资产一旦定稿，后续镜头提示词只**引用**它（"严格照抄上传的资产"），不再重新描述外貌。
