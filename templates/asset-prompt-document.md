# 资产文档模板 · assets_prompts.md

放在项目文件夹里（建议 `03_分镜与提示词/assets_prompts.md`）。整份文档是"生成清单"：导演照着一条一条生成，生成的图按条目名命名。

```
# 《片名》资产提示词文档
版本：v1（日期）
来源：剧本（第N稿）+ 分镜脚本；资产清单：assets_inventory.md
风格带（每条提示词都原样带上）：<千禧年代写实 · 冷灰蓝低饱和 · 单一光源 · 16:9>
状态：待导演逐条生成 → 生成后在条目后标 √ 与文件名
```

## 一、人物资产

每个人物：**一条身份提示词** + **每条变体一条独立提示词**。变体 = 服装变化 / 面容或身体状态变化（被打、湿透、有伤、被绑、换发型）。每条都写清"用于哪些镜"，避免传错图。

```
### <人物名>（年龄）
用于：sc5, sc6, sc7 …

#### A1 <人物名>·身份
用于：全部镜次（默认造型）
提示词：
【主体】<年龄、体型、长相、发型的客观描述>，单人，全身竖版，站在画面中间，自然站姿，中性表情。
【服装】<上衣、下装、鞋、配饰的逐件描述>
【背景与光线】干净的单色背景，<光从哪来>，均匀，没有影子堆积。
【禁止出现】不要夸张的肌肉线条，不要性感或暗示性的姿势，不要多余的人，不要多余的衣物或道具，不要文字水印，不要裁切身体。

#### A2 <人物名>·<变体名>（例：湿透）
用于：sc14, sc15
与身份图的差别：<一句话说清变的是什么>
提示词：
【主体】<年龄、体型、长相、发型>，单人，全身竖版……
【服装与身体状态】<湿透/带伤/被绑的具体物理描述：衣服贴身、颜色变深、头发湿；鼻梁与眼眶青紫发肿；手腕被铁链一圈圈缠住、链尾垂着>，血要克制（几颗针尖大小的血珠，不流动不下淌）。
【禁止出现】<这一条变体最容易跑偏的地方，逐条写死：不是手铐、没有铐环；不是血、不是红色；伤痕不要大片>
```

## 二、场景资产（每个场景 4 个方向）

先写**布局说明**，再写四条方向提示词。四条必须互相不打架——门在哪面墙，四条里都只能在那面墙。

```
### <场景名>（时间 · 内/外）
用于：sc3, sc4 …
#### 布局说明（写死，四个方向共用）
- 北面墙：<门/窗/家具>
- 东面墙：<…>
- 南面墙：<…>
- 西面墙：<…>
- 地面：<材质>　天花板/光源：<唯一光源位置>
- 家具位置唯一：<沙发×1、茶几×1、电视柜×1、桌×1 …>

#### B1 <场景名>·北向（摄像机站在北墙位置，朝南拍）
提示词：
【画面范围】<这个方向能看到什么：哪面墙、哪件家具、门的哪一侧>
【固定事实】<这一方向必须与另外三向一致的事实，逐条重写>
【禁止出现】<不能多出一扇门／不能出现第二个窗户／不能改变家具位置／不能出现第三个方向才有的东西>。
【光线】四个方向共用同一条光源设定：<…>

#### B2 <场景名>·东向（摄像机站在东侧，朝西拍）  …同结构
#### B3 <场景名>·南向 …   #### B4 <场景名>·西向 …
```

## 三、道具资产

状态与规则：<当前状态 + 永久规则，例如"钱包是三张红色一百元；不是十元；只有一个">
提示词：
【主体】<材质、颜色、尺寸感、磨损程度的客观描述>，单独一个，正面朝镜头，摆在干净平面上。

## 使用纪律

1. 一条提示词只放**一个主体**：人物图不塞两个人，道具图不塞两只手。
2. 所有资产图共用**同一条风格带**，逐字相同。
3. 生成的图**按条目名命名**（如 `A2_陈宇_湿透.png`），存进资产文件夹；条目后标 √。
4. 任何一条生成不理想，先告诉我问题，我改提示词（v2），不要自己在提示词里加词——加了就破坏了"同一条风格带"的一致性。
5. 资产一旦定稿，后续镜头提示词只**引用**它（"严格照抄上传的资产"），不再重新描述外貌。
